# ECONOMY — 生成物（`npm run econ`）

src/data から計算した基準価格と採算。給与 9,333円/日、電力 24円/kWh（高圧）、運賃 400円/t、売り手数料 4%、付加価値倍率 1.5。

- 手作業：作業員1人1日の利益（材料は基準価格で買う想定）
- 機械：機械1台1日の利益（操作員・電力・保守を引く）と、機械代の回収日数
- 自動化：自動機への改造費を、空いた操作員が別の機械を動かす前提で回収する日数
- 市場飽和：市場の1日の取引量を作るのに要る機械の台数
